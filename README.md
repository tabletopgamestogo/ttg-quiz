# TableTop Games To Go — Group Player-Profile Quiz

A self-contained, single-page quiz that matches a group's play style to one of four
player types and recommends board games from the TableTop Games To Go rental shelf.

**Live:** https://vernadettepacheco.github.io/ttg-quiz/

## Files

- `index.html` — the quiz (structure, styles, and flow)
- `quiz-engine.js` — game data and the recommendation-scoring logic

This is the public deploy target for GitHub Pages. Source development, design specs,
and business documentation live in a separate private repository.
